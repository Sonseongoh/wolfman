# wolfman 게임 디자인 문서

> 2026-07-31 컨셉 회의 결과. 이 문서가 게임 방향의 기준점이며, 회의로 결정이 바뀌면 이 문서를 갱신한다.

## 핵심 컨셉

**매 스테이지(또는 웨이브) 시작 시 하나의 달이 떠오른다.**

- 달은 확률에 따라 결정되며, 각 달은 고유한 희귀도와 전투 규칙을 가진다
- 희귀한 달일수록 스테이지 난이도는 높아지지만, 클리어 시 더 높은 등급의 보상을 얻는다

## 장르

**디펜스 + 마을 운영 + 뱀서라이크 전투**

## 기본 루프

```
스테이지(or 웨이브) 진입
→ 달 추첨
→ 달의 규칙 적용
→ 행동 선택: 마을에 남아 방어·운영 / 사냥에 나가 전투
→ 전투/생존/목표 수행
→ 클리어
→ 달 희귀도에 따른 보상 선택
→ 다음 스테이지 진입
```

## 달의 역할

달은 단순한 배경이 아니라 **이번 스테이지의 룰셋**이다.

- 어떤 적이 나오는가
- 플레이어 능력이 어떻게 변하는가
- 스테이지 목표가 어떻게 달라지는가
- 클리어 보상 등급이 어느 정도인가

## 달 테이블 (확정 — 2026-08-04, 실존 달 현상 기반 9종)

희귀도 총괄: Common 56% · Uncommon 24% · Rare 15% · Epic 4.5% · Legendary 0.5%

| 달 | 희귀도 | 확률 | 스테이지 효과 | 클리어 보상 |
|---|---|---|---|---|
| 초승달 | Common | 30% | 적 약하고 수 적음. 입문 밤 | 하 |
| 보름달 | Common | 26% | 변신 가능 기본 밤. 적도 활발 | 중 |
| 슈퍼문 | Uncommon | 13% | 달빛 과잉 — 변신 대폭 강화, 적도 강화 | 중상 |
| 하베스트문 | Uncommon | 11% | 수확의 달 — 재화·경험치 드랍 2배, 난이도 표준 | 재화 특화 |
| 울프문 | Rare | 9% | 동족의 밤 — 늑대 계열 적 대량, 야수 본능 강화 | 상 |
| 블루문 | Rare | 6% | 행운의 밤 — 희귀 스킬 확정 등장, 선택지 확대 | 스킬 특화 |
| 블러드문 | Epic | 2.5% | 피의 밤 — 쌍방 공격력 폭증 + 지속 출혈. 유리대포전 | 최상 |
| 블랙문 | Epic | 2% | 달 없는 밤 — 변신 불가, 시야 제한, 은신·회피 생존 | 최상 |
| 슈퍼 블루 블러드문 | Legendary | 0.5% | 150년의 달 — 특수 보스 / 변칙 스테이지 | 전설 |

- 검토 과정에서 제외: 상현달·하현달·마이크로문(표준의 변형이라 체감 차이 약함), 헌터스문
- 보관 아이디어: 헌터스문 — 사냥꾼 NPC들이 늑대인간인 나를 사냥하는 역전 밤 (추후 확장 후보)
- 특수 룰 필요: 블랙문(시야 제한), 슈퍼 블루 블러드문(보스). 나머지는 수치 조절로 구현 가능

## 성장 축 (2개)

1. **런 내 성장** — 전투 중 랜덤 선택지로 스킬·속성 강화 (현재 레벨업 시스템의 확장)
2. **영구 성장** — 마을 재화로 체력, 공격력, 갑옷 내구도 등 영구 강화

## 결정 사항

- 매 라운드 달 확인 후 행동 선택: 마을 방어·운영 vs 사냥
- 동료 시스템은 1차 MVP에서 **제외**

## 마을 페이즈 (확정 — 2026-08-07, #51)

라운드마다 "사냥 나가기 / 마을 남기"를 고르는데, **마을을 비우면 마을이 습격당한다.** 이게 두 선택을 저울에 올리는 축이다.

| | 사냥 나가기 | 마을 남기 |
|---|---|---|
| 수입 | 임시 골드 + 클리어 보너스 + 창고 수입 | 클리어 보너스 + 창고 수입 |
| 마을 | **무인 습격** — 시설이 깎인다 | 플레이어가 직접 방어 (#12) |
| 할 일 | 웨이브 생존 | 수리 · 방어 전투 · 영구 강화 구매 |

차이는 **임시 골드 하나**다. 사냥은 더 벌고, 마을은 더 지킨다.

### 시설 3채 — 역할과 효과

역할과 시설을 1:1로 묶는다. 파괴가 곧 하나의 상실로 읽히게 하기 위해서다 — 한 시설이 두 역할을 겸하면 "대장간이 파괴됐다"가 무슨 손실인지 플레이어가 셈을 해야 한다.

| 시설 | 역할 | 효과 | 최대 체력 | 수리비 |
|---|---|---|---|---|
| **망루탑** | 방어 | 마을 방어력 **+3** | 10 | 40G |
| **창고** | 생산 | 라운드 종료 시 금고 **+20G** | 10 | 30G |
| **대장간** | 정비 | **영구 강화 상점**(#13) 이용 가능 | 10 | 50G |

**효과는 이진이다** — 체력이 1이든 10이든 100%로 작동하고, 0이 되는 순간 완전히 멈춘다. 수리하면 즉시 돌아온다. 수리비가 남은 체력과 무관한 고정값이라, 효과를 체력에 비례시키면 매 라운드 "얼마나 깎였으니 지금 고칠까"라는 재미없는 산수를 시키게 된다.

창고 수입은 **패시브**다 — 사냥을 나가든 마을에 남든 들어온다. 마을에 남는 보상은 이미 "시설 피해 0 + 수리 시간 + 대장간 이용"으로 충분한데 수입까지 남기 전용으로 얹으면 저울이 반대로 기운다. 창고는 벌어주는 곳이 아니라 **지켜야 할 자산**이다.

### 무인 습격 — 마을을 비운 대가

사냥을 나간 라운드에 마을이 받는 피해. **전투를 시뮬레이션하지 않고 계산 한 번으로 처리한다.**

```
습격 위력   = 4 × 달 강도 × (1 + (라운드−1) × 0.15)
마을 방어력 = 살아있는 시설 수 × 1  +  망루탑 생존 시 +3  +  상점에서 구매한 강화
관통 피해   = max(0, 위력 − 방어력)
```

관통 피해는 **망루탑 → 창고 → 대장간** 순서로 들어가고, 한 채를 파괴하고 남으면 다음 시설로 이월된다. 망루탑이 방패라 먼저 부서지는 게 맞고, 대장간이 마지막이라 회복 수단(방어력 구매)이 끝까지 남는다.

**달 강도**는 새 데이터가 아니라 기존 `MoonData`의 `enemyDamageMultiplier × enemyCountMultiplier`다 — 적 한 마리의 위력 × 마릿수가 곧 그 밤이 마을을 덮치는 힘이다.

| 달 | 습격 강도 |
|---|---|
| 초승달 | 0.56 |
| 보름달 · 하베스트문 | 1.00 |
| 블루문 | 1.10 |
| 블랙문 | 1.17 |
| 슈퍼문 | 1.32 |
| 울프문 | 1.54 |
| 블러드문 | 1.92 |
| 슈퍼 블루 블러드문 | 1.95 |

3채가 온전할 때(방어력 6) 실제로 이렇게 나온다:

| 라운드 | 달 | 위력 | 관통 |
|---|---|---|---|
| 1 | 보름달 | 4.0 | 0 — 초반 유예 |
| 1 | 블러드문 | 7.7 | 1.7 |
| 5 | 울프문 | 9.9 | 3.9 |
| 10 | 보름달 | 9.4 | 3.4 |
| 10 | 블러드문 | 18.0 | 12.0 — 시설 한 채가 날아간다 |
| 20 | 보름달 | 15.4 | 9.4 |

마을에 남은 라운드에는 이 계산을 하지 않는다 — 플레이어가 직접 막는다(#12).

### 시설 전멸 = 게임오버

시설 3채가 모두 파괴되면 런이 끝난다. 마을을 잃어도 게임이 계속되면 장르에서 "디펜스"는 이름만 남고, 마을을 비우는 선택이 골드만 걸린 가벼운 도박이 된다.

**나선은 구조로 막는다.** 방어력을 망루탑 한 채에 몰지 않고 시설마다 흩어놨다:

```
3채 온전 + 망루탑 정상 →  6
망루탑만 파괴          →  2   ← "다음엔 못 버틴다"가 눈에 보인다
1채만 남음             →  1
```

전멸까지 최소 두세 라운드가 걸리고, 그동안 귀환 화면에서 방어력이 깎이는 걸 본다. 모르는 사이 지는 게 아니라 **무리하는 걸 알면서 무리하다 지는 것**이다.

플레이어 사망(사냥 중이든 방어 중이든)은 기존 게임오버가 그대로 처리한다. "방어 실패"는 오직 시설 전멸만 가리킨다.

### 마을에서 하는 일

1. **수리** — 시설에 다가가 `E`. 금고에서 고정 비용 차감, 만피 복구
2. **방어 전투**(#12) — 적이 플레이어가 아니라 시설을 노린다
3. **영구 강화 구매**(#13) — 대장간에서. 플레이어 스탯 + **마을 방어력 +1 / 150G**(반복 구매)
4. **라운드 종료**

마을 방어력을 골드로 살 수 있어야 하는 이유는 후반 때문이다. 습격 위력은 라운드마다 커지는데 방어력이 고정이면 언젠가 사냥을 나가는 것 자체가 자살이 되고, 선택지가 사라져 마을에 갇힌다.

이 셋이 루프를 닫는다:

```
마을에 남는다 → 창고 수입 + 망루탑 수리 → 방어 갖춰짐
   → 사냥 나간다 → 임시 골드를 크게 벌어옴
      → 대장간에서 영구 강화 → 더 깊이 사냥
         (그 사이 마을은 무방비 → 시설이 깎임 → 다시 남아야 함)
```

수치는 전부 첫 조정 대상이다. 실플레이로 잡는다.

## 사냥 탈출 포탈 (제안 — 회의 대기, 2026-08-06)

"언제든 나가기 버튼" 대신, **웨이브 시작 시 일정 확률로 탈출 포탈이 열리는** 방식.

- 기본 확률 **10%** (웨이브 2부터 판정 — 1웨이브는 사냥/마을 선택 직후라 제외)
- 포탈은 **그 웨이브 동안만 유지** — 적을 뚫고 걸어가서 닿아야 탈출 (웨이브 클리어 시 닫힘)
- 탈출 = 살아서 귀환 → 임시 골드 금고 확정 (#8 뱅킹과 연결)
- 재미 포인트: 언제 뜰지 모름 + 떴을 때 "지금 탈까, 한 탕 더 할까" 선택

### 달별 확률 조정안 (수치는 회의에서 확정)

| 달 | 성격 | 탈출구 확률(안) |
|---|---|---|
| 초승달 | 평온한 밤 | 12% |
| 보름달 | 표준 | 10% |
| 슈퍼문 | 강화된 밤 | 8% |
| 하베스트문 | 드랍 2배 | 15% — "수확했으면 챙겨 나가라" |
| 울프문 | 늑대 강화 | 10% |
| 블루문 | 희귀한 행운 | 20% — 쉬어가는 밤 |
| 블러드문 | 고위험 고보상 | 3% — 피의 밤은 쉽게 못 빠져나감 |
| 블랙문 | 어둠 | 5% |
| 슈퍼 블루 블러드문 | 전설 | 15%(안) — 0%로 하면 잭팟이 함정이 되므로, 대신 적 강화로 난이도 유지 |

원칙: **희귀할수록 탈출구가 안 뜬다** (잭팟 달 = 각오하는 밤). 단 전설만은 예외로 탈출을 열어줘 보상을 회수할 수 있게. 구현은 `MoonData.exitChance` 필드 하나로 가능.
