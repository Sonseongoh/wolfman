# wolfman 게임 디자인 문서

> 2026-07-31 컨셉 회의 결과. 이 문서가 게임 방향의 기준점이며, 회의로 결정이 바뀌면 이 문서를 갱신한다.
> 마을 페이즈는 2026-08-10 에 전면 개정됐다 — "밤과 낮" 절과 [ADR 0004](adr/0004-마을을-위협하는-것은-플레이어-자신이다.md) 참고.

## 스토리

이 마을 사람들은 내가 무엇인지 알면서 나를 품었다. 대장간 주인은 내 발톱을 버티는 무기를 만들고, 창고지기는 내 몫을 따로 떼어 둔다. 망루탑은 밖을 보려고 세운 게 아니다 — **나를 붙들어 두려고 세웠다.**

나는 여기에 어울린다. 여기 있고 싶다.

그래서 밤마다 산으로 간다. 굶으면 이성이 흐려지고, 흐려지면 가장 가까운 것을 덮치기 때문이다. 산의 것들은 마을을 노리지 않는다. 그저 먹이다. **나는 지키러 가는 게 아니라 먹으러 간다.**

그런데 먹을수록 힘이 차오르고, 차오른 힘은 내 것이 아니다. 굶어서 미치지 않으려고 나가는데, 나갈수록 다른 방식으로 나를 잃는다. **굶주림이 나를 밖으로 밀고, 야성이 나를 안으로 붙든다.** 어느 쪽으로도 오래 갈 수 없다.

내가 이 마을을 지킨다는 말은 오직 하나를 뜻한다 — **내가 이들을 해치지 않는 것.**

열 밤. 그때까지 사람으로 남을 수 있다면.

## 핵심 컨셉

**매 밤 해질녘에 하나의 달이 떠오른다.**

- 달은 확률에 따라 결정되며, 각 달은 고유한 희귀도와 전투 규칙을 가진다
- 희귀한 달일수록 그 밤의 난이도는 높아지지만, 클리어 시 더 높은 등급의 보상을 얻는다
- 달은 **야성이 차오르는 속도**도 정한다 — 그래서 "오늘 밤 나갈 수 있는가"가 밤마다 달라진다

## 장르

**디펜스 + 마을 운영 + 뱀서라이크 전투**

## 기본 루프

```
낮 — 마을에서 인간으로. 정해진 횟수만큼 행동한다 (사기 / 고치기 / 묶이기)
→ 해질녘 — 달이 뜬다. 그 밤의 룰셋이 정해진다
→ 선택 — 사냥을 나갈까, 남을까
→ 밤 — 나가면 웨이브, 남으면 아무 일도 없다
→ 다음 낮 (길이는 지난밤이 정한다)
```

열 밤을 채우면 클리어. 사냥터에서 죽거나 시설이 전멸하면 런이 끝난다.

## 달의 역할

달은 단순한 배경이 아니라 **이 밤의 룰셋**이다.

- 어떤 적이 나오는가
- 플레이어 능력이 어떻게 변하는가
- **야성이 얼마나 빨리 차오르는가** — 곧 이 밤에 얼마나 오래 머물 수 있는가
- 클리어 보상 등급이 어느 정도인가

마지막에서 두 번째가 선택을 만든다. 달이 야성 속도를 정하고 내 야성이 이미 어디까지 차 있느냐가 겹치므로, **같은 달이라도 밤마다 답이 다르다.** 야성이 바닥이면 보름달도 나갈 만하고, 팔 할이면 초승달에도 못 나간다.

## 성장 축 (3겹 — 수명이 다르다)

| 겹 | 수명 | 정체 |
|---|---|---|
| **그 밤의 것** | 그 밤 | 사냥터에서 줍는 아이템·효과. 해가 뜨면 사라진다 |
| **야성** | 런 전체 | 내 안에 쌓이는 힘. 강해지는 대신 몸을 잃어간다 |
| **영구 강화** | 게임 전체 | 대장간이 몸에 새긴 것 |

**"스킬"이라고 부르지 않는다.** 배운 기술은 사라지지 않는다. 그 밤만 남는 것이라면 주운 것이거나 달이 씌워준 것이어야 이름과 수명이 맞는다.

밤 사이의 연속성은 야성이 맡는다 — 야성이 높은 채로 나가면 처음부터 강하다.

## 결정 사항

- 매 밤 달을 보고 고른다: 사냥 나가기 vs 마을에 남기
- **마을을 위협하는 것은 플레이어 자신뿐이다** (ADR 0004). 외부의 습격은 없다
- 동료 시스템은 1차 MVP에서 **제외**

## 밤과 낮 (확정 — 2026-08-10, #51 개정)

> 2026-08-07판의 "무인 습격" 설계를 대체한다. 왜 갈아엎었는지는 [ADR 0004](adr/0004-마을을-위협하는-것은-플레이어-자신이다.md).

매 밤 "사냥 나가기 / 마을에 남기"를 고른다. 두 선택은 서로 다른 것을 앗아간다.

| | 사냥 나가기 | 마을에 남기 |
|---|---|---|
| 수입 | 임시 골드 + 클리어 보너스 | **없음** |
| 야성 | 오른다 | 내려간다 |
| 굶주림 | 내려간다 (먹는다) | 오른다 |
| 다음 낮 | 짧다 — 지쳐 돌아온다 | 온전하다 |

클리어 보너스를 사냥 전용으로 둔 이유는 이것이다 — 안전한 쪽이 위험한 쪽과 같은 수입을 주면 사냥할 이유가 사라진다. 마을에 남는 대가는 **그 밤의 벌이를 통째로 포기하는 것**이다.

그리고 **어느 쪽도 안전하지 않다.** 사냥은 야성 쪽으로, 마을은 굶주림 쪽으로 민다. 양 끝 모두 폭주로 이어진다.

### 축 — 야성과 굶주림

```
굶주림 ◀──────────────── 안전 ────────────────▶ 야성
  약해진다                              강해지고 거칠어진다
  이성을 잃는다                            몸을 빼앗긴다
       ▲                                        ▲
   마을에 머물면                            사냥을 나가면
```

값 하나에 임계선 둘. 어느 끝에 닿아도 결과는 같다 — **폭주.**

**야성 쪽**

| | |
|---|---|
| 낮음 | 내 몸이다 |
| 높음 | 몸이 앞서 나간다 — 자동 돌진, 멈추기 어려움, 좁아지는 시야 |
| 한계 초과 | 폭주 |

야성이 오르면 **강해지는 동시에 거칠어진다.** 순수 강화로 두면 화면 구석 숫자로 남지만, 몸이 과잉해지면 경고가 UI 없이 손끝으로 전달되고 거친 몸을 다루는 것 자체가 실력이 된다. 다만 **입력을 무시하거나 뒤집지는 않는다** — 의도는 반영하되 결과가 과해지는 쪽이어야 "게임이 씹었다"가 아니라 "내가 못 다뤘다"로 읽힌다.

**굶주림 쪽** — 단계로 나빠진다.

| 단계 | 몸 | 마을 |
|---|---|---|
| 포식 | — | — |
| 허기 | 공격력 ↓ | — |
| 주림 | 공격력 ↓↓, 최대 체력 −1 | — |
| 아사 | 공격력 ↓↓↓, 최대 체력 −2 | **주민이 피한다** — 상점이 닫힌다 |
| 한계 | 폭주 | |

아사 단계에서 상점을 닫는 게 핵심이다. 마을에 남는 유일한 이유가 상점인데 굶주릴수록 그게 닫히므로, **머물 이유를 하나씩 없애는 방식으로** 등을 떠민다. 규칙으로 "나가라"고 하지 않는다.

**굶주릴수록 한 입이 크다.** 깊을수록 처치당 회복량이 커진다. 이게 없으면 아사 단계는 데드락이다 — 약하고, 상점도 못 쓰고, 나가야 푸는데 나가면 죽는다. 회복이 크면 야윈 몸으로 나가도 첫 먹이를 물면 숨통이 트여서, 절망이 아니라 도박이 된다.

**달은 야성이 차오르는 속도를 정한다.** 보름달은 빨리, 초승달은 천천히. 그래서 같은 달이라도 내 야성이 지금 어디인지에 따라 답이 달라진다 — 야성이 바닥이면 보름달도 나갈 만하고, 팔 할이면 초승달에도 못 나간다. 답이 외워지지 않는 건 이 결합 덕분이다.

### 폭주 — 마을을 덮치는 것은 나다

한계를 넘으면 몸을 빼앗긴다. **조작은 남지만 막지 못한다** — 움직일 수는 있으나 공격은 자동이고 대상이 시설이라, 달려가도 막을 수 없고 닿으면 부서진다.

별개의 벌칙이 아니라 같은 곡선의 끝이다.

```
야성 낮음  →  내 몸이다
야성 높음  →  몸이 앞서간다
한계 초과  →  몸을 빼앗긴다
```

**내가 부순 것은 완전히 돌아오지 않는다.** 금고 골드로 고치면 기능은 복구되지만 최대 체력이 영구히 줄어든다. 온전히 수리되면 폭주가 "수리비 얼마짜리 사고"로 환산되고, 환산되는 순간 죄가 비용이 된다.

### 시설 3채 — 축에 1:1

역할과 시설을 1:1로 묶는다. 파괴가 곧 하나의 상실로 읽히게 하기 위해서다.

| 시설 | 맡는 것 | 효과 | 최대 체력 |
|---|---|---|---|
| **대장간** | 힘 | **영구 강화 상점**(#13) 이용 가능 | 10 |
| **창고** | 굶주림 | 굶주림이 차오르는 속도를 늦춘다 | 10 |
| **망루탑** | 야성 | 야성이 차오르는 속도를 늦춘다. **묶이는 장소**이기도 하다 | 10 |

**효과는 이진이다** — 체력이 1이든 10이든 100%로 작동하고, 0이 되는 순간 멈춘다.

여기서 나선이 생긴다.

> 폭주로 망루탑이 부서지면 → 야성이 더 빨리 찬다 → 다음 폭주가 더 빨리 온다 → 또 부순다

실패가 밖에서 오지 않는다. **내가 감아 내려간다.**

창고지기가 내 몫을 떼어 두지만 그걸 먹어서 굶주림을 되돌릴 수는 없다 — 짐승의 허기에는 모자라서 **늦출 뿐이다.** 마을에서 굶주림을 풀 수 있으면 나를 밖으로 미는 힘이 통째로 사라진다.

### 낮 — 마을에서 하는 일

시간이 흐르는 것만으로 야성이 식고 굶주림이 오른다. 머문 만큼이다.

그 위에 **행동이 얹힌다. 수가 정해져 있다** — 어젯밤 나갔으면 적고, 쉬었으면 넉넉하다.

| 행동 | 치르는 것 | 얻는 것 |
|---|---|---|
| **대장간에서 산다** | 금고 골드 | 영구 강화 — 런을 넘어 남는다 (#13) |
| **시설을 고친다** | 금고 골드 | 체력 복구 (최대치는 안 돌아온다) |
| **묶어달라고 부탁한다** | 하루 통째 | 야성이 크게 내려간다 |

세 번째가 슬롯을 저울로 만든다. 앞의 둘은 같은 화폐(골드)를 쓰므로 계산이지만, 묶이기는 다른 화폐를 쓴다 — **골드를 쓸까, 나를 눌러둘까.** 환산이 안 되는 두 값 사이에서 고르는 것이라야 선택이다.

그리고 저절로 따라오는 게 있다. 묶이면 하루를 통째로 쓰니 **굶주림이 그만큼 크게 오른다.** 야성을 눌러 내린 값을 굶주림으로 치른다 — 규칙을 더하지 않아도 축이 알아서 작동한다.

밤에 남는 쪽을 골라도 마찬가지다. 마을에서 보내는 시간이 길수록 야성은 더 식고 굶주림은 더 오른다.

### 재화 — 잃는 시점이 셋

| 층 | 재화 | 사라지는 때 |
|---|---|---|
| 사냥 한 판 | 임시 골드 | 죽으면 즉시 |
| 런 (열 밤) | 금고 골드 | 런이 끝나면 |
| 게임 전체 | 영구 강화 | 안 사라진다 |

금고 골드를 런 한정으로 둔 이유는 이것이다 — 죽어도 남으면 런이 끝나도 끝나는 게 없어서, 사냥을 막 나가도 손해가 아니고 마을에 갈 이유도 안 생긴다. 사라지게 두면 **"모은 걸 언제 힘으로 바꿀까"**가 매일의 질문이 되고, 그게 마을에 가는 이유가 된다.

### 끝나는 방식

| 결말 | 조건 |
|---|---|
| **사람으로 남는다** | 열 밤을 넘긴다 |
| **돌아오지 못한다** | 사냥터에서 죽는다 — 런 종료 |
| **버려진다** | 시설 셋이 모두 부서진다. 품어준 사람들이 마지막에 등을 돌린다 |

셋 중 둘은 내가 불러온 것이다. 사냥터의 적은 마을에 오지 않으므로, 마을을 부수는 것은 언제나 나다.

**"방어 실패"는 쓰지 않는다.** 막을 습격이 없다.

### 루프

```
        ┌──────────── 밤에 나간다 ────────────┐
        │  임시 골드 ↑   야성 ↑   굶주림 ↓    │
   달이 뜬다                              선을 넘으면
        │  금고를 힘으로 바꾼다                │  내가 마을을 덮친다
        │  야성 ↓   굶주림 ↑   벌이 없음      │         │
        └──────────── 낮에 남는다 ────────────┘         ▼
                              │                    마을이 야윈다
                              └──── 나를 덜 붙든다 ◀────┘
```

바깥 고리가 하루의 순환이고, 안쪽 고리가 내가 감아 내려가는 나선이다.

수치는 전부 첫 조정 대상이다. 실플레이로 잡는다.

## 사냥 탈출 포탈

"언제든 나가기 버튼" 대신, **웨이브 시작 시 일정 확률로 탈출 포탈이 열리는** 방식. 사냥은 무한 웨이브이므로 밤을 끝내는 길은 셋뿐이다.

| 끝나는 방식 | 결과 |
|---|---|
| 포탈로 나간다 | 인간으로 귀환. 임시 골드가 금고로 확정 |
| 야성이 한계에 닿는다 | **짐승이 되어 귀환.** 마을을 덮친다 |
| 죽는다 | 런 종료 |

야성이 두 번째 시계라서, 포탈이 안 떠도 밤은 반드시 끝난다. **다만 야성이 높다고 포탈이 잘 뜨게 만들지는 않는다** — 확률을 야성에 연동하면 "이제 나가라"는 신호가 되어 긴장이 꺾인다. 야성이 어디인지 알고 나가는 것은 플레이어이므로, 못 나가고 폭주하는 것도 그 베팅의 결과다.

- 기본 확률 **10%** (코드 현재값: 5웨이브부터 판정, `WaveManager.portalMinWave`)
- 포탈은 **그 웨이브 동안만 유지** — 적을 뚫고 걸어가서 닿아야 탈출 (웨이브 클리어 시 닫힘)
- 탈출 = 살아서 귀환 → 임시 골드 금고 확정 (#8 뱅킹과 연결)
- 재미 포인트: 언제 뜰지 모름 + 떴을 때 "지금 탈까, 한 탕 더 할까" 선택 — 야성이 높을수록 이 질문이 무거워진다

### 달별 확률 조정안 (수치는 회의에서 확정)

| 달 | 성격 | 탈출구 확률(안) |
|---|---|---|
| 초승달 | 평온한 밤 | 12% |
| 보름달 | 표준 | 10% |
| 슈퍼문 | 강화된 밤 | 8% |
| 하베스트문 | 드랍 2배 | 15% — "수확했으면 챙겨 나가라" |
| 울프문 | 늑대 강화 | 10% |
| 블루문 | 희귀한 행운 | 20% — 쉬어가는 밤 |
| 블러드문 | 고위험 고보상 | 3% — 피의 밤은 쉽게 못 빠져나감 |
| 블랙문 | 어둠 | 5% |
| 슈퍼 블루 블러드문 | 전설 | 15%(안) — 0%로 하면 잭팟이 함정이 되므로, 대신 적 강화로 난이도 유지 |

원칙: **희귀할수록 탈출구가 안 뜬다** (잭팟 달 = 각오하는 밤). 단 전설만은 예외로 탈출을 열어줘 보상을 회수할 수 있게. 구현은 `MoonData.exitChance` 필드 하나로 가능.

## 미결정 / 다음 회의 주제 (추가되면 갱신)

- **수치 전부** — 행동 슬롯 수, 야성·굶주림 속도, 임계값, 열 밤의 N, 영구 강화 가격
- 폭주 1회에 몇 채를 얼마나 부수는가
- 영구 강화의 항목과 저장 방식 (#13)
- 주민을 실제 NPC로 등장시킬지 (서사에는 "날 묶는 손"으로 이미 들어와 있다)
- 변신 시스템 상세 — `MoonData.transformAllowed`(블랙문)를 아직 아무 데서도 읽지 않는다
- 탈출 포탈 달별 확률 (`MoonData.exitChance` 필드 하나로 가능)
