# wolfman 게임 디자인 문서

> 2026-07-31 컨셉 회의 결과. 이 문서가 게임 방향의 기준점이며, 회의로 결정이 바뀌면 이 문서를 갱신한다.

## 핵심 컨셉

**매 스테이지(또는 웨이브) 시작 시 하나의 달이 떠오른다.**

- 달은 확률에 따라 결정되며, 각 달은 고유한 희귀도와 전투 규칙을 가진다
- 희귀한 달일수록 스테이지 난이도는 높아지지만, 클리어 시 더 높은 등급의 보상을 얻는다

## 장르

**디펜스 + 마을 운영 + 뱀서라이크 전투**

## 기본 루프

```
스테이지(or 웨이브) 진입
→ 달 추첨
→ 달의 규칙 적용
→ 행동 선택: 마을에 남아 방어·운영 / 사냥에 나가 전투
→ 전투/생존/목표 수행
→ 클리어
→ 달 희귀도에 따른 보상 선택
→ 다음 스테이지 진입
```

## 달의 역할

달은 단순한 배경이 아니라 **이번 스테이지의 룰셋**이다.

- 어떤 적이 나오는가
- 플레이어 능력이 어떻게 변하는가
- 스테이지 목표가 어떻게 달라지는가
- 클리어 보상 등급이 어느 정도인가

## 달 테이블 (초안)

| 달 | 희귀도 | 등장 확률 | 스테이지 효과 | 클리어 보상 |
|---|---|---|---|---|
| 초승달 | Common | 35% | 적이 약하고 수가 적음 | 일반 보상 |
| 반달 | Common | 30% | 표준 난이도 | 일반~고급 보상 |
| 보름달 | Rare | 20% | 플레이어 변신 강화, 적도 강화 | 고급 보상 |
| 붉은달 | Epic | 10% | 적과 플레이어 모두 공격적 강화, 지속 피해 | 희귀 보상 |
| 검은달 | Epic | 4.5% | 시야 제한, 변신 불가, 은신/회피 중심 | 희귀~영웅 보상 |
| 100년의 달 | Legendary | 0.5% | 특수 보스 또는 변칙 스테이지 | 전설 보상 |

## 성장 축 (2개)

1. **런 내 성장** — 전투 중 랜덤 선택지로 스킬·속성 강화 (현재 레벨업 시스템의 확장)
2. **영구 성장** — 마을 재화로 체력, 공격력, 갑옷 내구도 등 영구 강화

## 결정 사항

- 매 라운드 달 확인 후 행동 선택: 마을 방어·운영 vs 사냥
- 동료 시스템은 1차 MVP에서 **제외**

## 미결정 / 다음 회의 주제 (추가되면 갱신)

- "스테이지제 vs 웨이브제" 확정
- 마을 방어 실패 시 페널티 (게임오버? 재화 손실?)
- 사냥 vs 방어 선택의 트레이드오프 설계 (사냥 나가면 마을은 누가 지키나)
- 변신 시스템 상세 (보름달 전용? 게이지제?)
